## 📋 微信后台配置（必须完成）

### 1. 服务器域名配置
登录 https://mp.weixin.qq.com → 开发 → 开发管理 → 开发设置

**必须添加的域名：**
```
request 合法域名（API 请求）：
- https://your-api-domain.com（替换为你的实际域名）

socket 合法域名（如有关实时功能）：
- wss://your-websocket-domain.com

uploadFile 合法域名（如有图片上传）：
- https://your-upload-domain.com

downloadFile 合法域名（如有文件下载）：
- https://your-download-domain.com
```

⚠️ **注意：**
- 所有域名必须使用 HTTPS
- 域名必须已备案
- 每个类型最多 20 个域名

### 2. 服务类目设置
登录 https://mp.weixin.qq.com → 设置 → 基本设置 → 服务类目

**推荐类目：**
```
主类目：生活服务 - 工具
子类目：家庭生活 / 效率工具
```

⚠️ **注意：**
- 如果有关支付功能，必须添加「在线交易」类目
- 如果有社区功能，必须添加「社交」类目并申请资质

### 3. 隐私设置
登录 https://mp.weixin.qq.com → 设置 → 基本设置 → 隐私设置

**必须填写：**
```
隐私保护指引：https://your-domain.com/privacy
（或者：在小程序内展示隐私协议，填写「小程序内」）
```

### 4. 接口权限申请
登录 https://mp.weixin.qq.com → 开发 → 开发管理 → 接口设置

**可能需要的权限：**
- [ ] 用户信息（wx.getUserInfo）
- [ ] 地理位置（如有关定位功能）
- [ ] 摄像头（如有拍照功能）
- [ ] 录音（如有语音功能）
- [ ] 微信支付（如有关支付）

## 🚀 提交审核步骤

1. **上传代码**
   - 打开微信开发者工具
   - 导入项目（目录：/Users/zerone/WorkBuddy/20260420104543/miniprogram）
   - 点击「上传」按钮
   - 填写版本号：1.0.0
   - 填写版本描述
   - 点击「上传」

2. **提交审核**
   - 登录 https://mp.weixin.qq.com
   - 进入「版本管理」
   - 找到刚上传的开发版本
   - 点击「提交审核」
   - 填写审核信息（参考上方「审核说明」）
   - 上传截图
   - 点击「提交审核」

3. **等待审核结果**
   - 通常 1-3 个工作日出结果
   - 会收到微信通知（服务通知）
   - 如果被拒绝，查看拒绝原因并修改后重新提交
