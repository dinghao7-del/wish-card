- 已新增关键路径浏览器冒烟测试，覆盖游客、计划、AI 分析和商业资源后台入口。

## 2. 最后 11% 完成情况

### A. 上线前必须修，已完成

这些是阻塞可交付体验的事项，本轮已经闭环。

1. 主路径再跑一轮全量冒烟
   - Chromium 冒烟已覆盖游客入口、计划落地、AI 分析和商业资源后台入口。
   - 关键单测已覆盖游客隔离、AI 建档归档、计划域、公共日历、语音日程、推荐网关、推荐库存和成员凭证。

2. 离线优先一致性复核
   - 游客模式保持本地独立，不进入云端同步。
   - 登录用户继续保持本地优先写入和同步队列。
   - 公共时间远程源已增加缓存回退。

3. 安全与权限上线债
   - 新增成员凭证统一封装，新保存的 PIN/密码不再以明文形式进入本地/云端成员字段。
   - 旧明文数据保持兼容验证，后续保存时会转为本地凭证格式。
   - 敏感操作二次确认兼容新凭证格式。
   - 商业推荐继续只用行为标签、场景和粗粒度画像，不展示隐私字段。

4. UI 关键页面收口
   - 欢迎页、游客模式和主要入口已进入浏览器冒烟范围。
   - 计划中心、计划详情、AI 分析和资源后台的核心入口已验证可访问。

### B. 体验优化，已完成当前版本范围

这些不阻塞主线，但会明显影响用户感觉；当前版本先完成主闭环体验。

1. AI 建档流程继续减步骤
   - 继续减少表单感。
   - 优先通过自然语言一次性采集课外班、兴趣爱好、每日练习、家长工作时间。

2. 计划拆解后的微调体验
   - 子计划生成后，提供“下一步补时间/生成任务/看复盘”的连续动作。
   - 目标型计划增加里程碑编辑入口。

3. 语音助手表达优化
   - 确认卡里的影响列表更清楚。
   - 冲突说明更像家长能理解的话，而不是系统告警。

### C. 二期扩展，保持后置

这些不进入当前收尾冲刺。

1. 真实远程公共数据接入
   - 接正式节假日、校历、天气/灾害/公共事件接口。
   - 增加数据源可信等级和更新时间展示。

2. 社区高知家庭模板沉淀
   - 模板质量评分。
   - 一键改编到自家日程。
   - 高质量模板榜单。

3. 商业推荐正式运营后台
   - 资源 CRUD 表单。
   - 合作标识。
   - 转化追踪和投放分组。

## 5. 当前判断

项目当前这一轮主线改造已经完成，可以进入内测验证阶段。

短期目标不是把长期愿景全部做完，而是把家庭 AI 管家的第一版核心体验做稳：

家庭画像 -> AI 日程/计划 -> 任务执行 -> 积分奖励 -> 心愿兑现 -> 周期复盘 -> 智能推荐。

只要这条链路稳定，产品就具备内测和继续商业验证的基础。
