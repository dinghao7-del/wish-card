# 小天才手表真机测试任务单与提审材料包

## 1. 执行目标

本阶段不承诺“已上线小天才”，只完成可交付的真机验证和提审材料准备。

| 目标 | 完成标准 |
| --- | --- |
| 真机能力验证 | 计步、运动、相机、地点至少明确为可用、待授权、不支持或需平台确认。 |
| 数据链路验证 | SDK 事件能转换为 `WatchActivitySnapshot` 或 `WatchProofSnapshot`，并生成家长审核摘要。 |
| 权限兜底验证 | 拒绝权限后仍可查看任务、手动提交、由家长确认。 |
| 提审材料准备 | 截图、权限说明、隐私政策补充、用户协议补充、儿童友好说明齐备。 |

## 6. 权限与隐私提审文案

### 6.1 运动/传感器

申请原因：用于统计家庭任务中的步数、运动时长或动作估算，帮助监护人确认任务完成情况。

边界说明：仅上传任务相关汇总值，不上传原始传感器流，不做医疗、健康诊断或体能评估。

拒绝影响：拒绝后仍可查看任务并手动提交。

### 6.2 相机

申请原因：用于拍摄任务成果，例如整理后的桌面、完成的作品或运动打卡结果。

边界说明：照片仅给监护人审核，不公开展示，不要求拍摄儿童人脸。

拒绝影响：拒绝后可改为文字说明或由监护人线下确认。

### 6.3 定位

申请原因：用于地点提醒或地点标签命中，例如到公园后提醒开始任务。

边界说明：只上传地点标签命中结果，不展示实时轨迹，不保存完整路线，不用于广告或商业推荐。

拒绝影响：拒绝后仍保留普通任务提醒和手动提交。

## 7. 用户协议补充要点

- 该功能服务于家庭任务、奖励和亲子协作。
- 儿童手表端只显示与本人相关的任务和奖励进度。
- 监护人可查看任务提交内容、审核结果和奖励发放记录。
- 监护人可删除任务记录或相关证明。
- 传感器、照片和地点均为可授权能力；拒绝授权不影响基础任务使用。

## 8. 儿童友好说明

| 场景 | 文案 |

| 运动 | 手表帮你记录这次运动用了多久。 |
| 动作估算 | 手表会估一估动作次数，爸爸妈妈最后确认。 |
| 拍照 | 你可以拍一张完成后的照片给爸爸妈妈看。 |
| 地点 | 到了指定地点，手表会提醒你开始或提交。 |
| 拒权 | 不打开也没关系，你仍然可以手动提交。 |
