# Forest Family UI 设计规范文档

> 基于 54 个知名设计系统的最佳实践，为 Forest Family 项目量身定制的高保真 UI 设计规范

---

## 一、设计理念

### 1.1 核心定位
- **产品定位**：家庭成长激励应用（家长管理 + 孩子任务奖励）
- **目标用户**：6-15 岁儿童及其家长
- **情感调性**：温暖、鼓励、成长、森林自然

### 1.2 设计关键词
| 关键词 | 设计表达 |
|--------|----------|
| 温暖 | 暖色调背景、微圆角、手写字体 |
| 成长 | 渐变色彩、上升动画、数字增长动效 |
| 森林 | 品牌绿色、自然插画、绿叶装饰 |
| 奖励 | 星星积分、金色点缀、庆祝动效 |

### 1.3 参考设计系统
- **Notion** - 温暖极简、负字距控制
- **Airbnb** - 家庭友好、情感化插画
- **Linear** - 暗色模式 luminance 分层
- **Mintlify** - 清爽文档、清晰层次

## 六、阴影系统

### 6.1 三层阴影体系

| 层级 | 名称 | 阴影值 | 用途 |
|------|------|--------|------|
| Level 1 | Whisper | `0 1px 2px rgba(0,0,0,0.04)` | 输入框、次要卡片 |
| Level 2 | Card | `0 2px 6px rgba(0,0,0,0.04), 0 4px 8px rgba(0,0,0,0.08)` | 标准卡片 |
| Level 3 | Elevated | `0 3px 7px rgba(0,0,0,0.02), 0 7px 15px rgba(0,0,0,0.02), 0 14px 28px rgba(0,0,0,0.04)` | 弹窗、浮层 |

```css
.shadow-card {
  box-shadow: 0 0 0 1px rgba(0,0,0,0.02), 0 2px 6px rgba(0,0,0,0.04), 0 4px 8px rgba(0,0,0,0.08);

.shadow-card-hover {
  box-shadow: 0 0 0 1px rgba(0,0,0,0.04), 0 4px 12px rgba(0,0,0,0.06), 0 8px 16px rgba(0,0,0,0.1);

.shadow-elevated {
  box-shadow: 0 0 0 1px rgba(0,0,0,0.01), 0 3px 7px rgba(0,0,0,0.02), 0 7px 15px rgba(0,0,0,0.02), 0 14px 28px rgba(0,0,0,0.04);
}
```

## 七、动画系统

### 7.1 基础动画 token

```typescript
const MOTION = {
  // 时长
  duration: {
    instant: 100,    // 微交互
    fast: 150,       // 快速反馈
    normal: 200,     // 标准过渡
    slow: 300,       // 页面切换
    slower: 500,      // 强调动画
  },
  
  // 缓动
  easing: {
    default: [0.4, 0, 0.2, 1],      // 标准
    in: [0.4, 0, 1, 1],              // 入场
    out: [0, 0, 0.2, 1],             // 出场
    bounce: [0.68, -0.55, 0.27, 1.55], // 弹性
  }
}
```

### 7.2 组件动画规范

| 动画 | 属性 | 时长 | 缓动 | 触发 |
|------|------|------|------|------|
| 入场淡入 | opacity 0→1 | 200ms | ease-out | 页面加载 |
| 入场上滑 | y: 12→0, opacity 0→1 | 250ms | ease-out | 列表项 |
| 悬停放大 | scale 1→1.02 | 150ms | ease | 卡片悬停 |
| 按压缩小 | scale 1→0.97 | 100ms | ease | 按钮点击 |
| 页面切换 | opacity, x: 8→0 | 300ms | ease | 路由切换 |
| 星星增加 | scale 1→1.2→1 | 400ms | bounce | 积分变化 |

### 7.3 连续动画

```css
/* 浮动动画 */
@keyframes float {
  0%, 100% { transform: translateY(0) rotate(0deg); }
  50% { transform: translateY(-10px) rotate(5deg); }
}

/* 脉冲动画 */
@keyframes pulse-soft {
  0%, 100% { opacity: 0.3; transform: scale(1); }
  50% { opacity: 0.6; transform: scale(1.1); }
}

/* 弹跳动画 */
@keyframes bounce-subtle {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-5px); }
}
```
