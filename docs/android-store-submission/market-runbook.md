# Android 各市场上架步骤

## 通用准备

1. 生成正式 release 包：
   - 国内市场：`APK`
   - Google Play：`AAB`
2. 准备应用图标、截图、应用介绍、更新说明、隐私政策链接、账号注销说明、测试账号。
3. 准备主体资质：实名认证/企业认证、软著或电子版权、ICP 备案、APP 备案。
4. 先提交 2-3 个市场试审，按驳回意见统一修资料，再批量投放。

## Google Play

1. 登录 Google Play Console。
2. 创建应用，选择应用名称、默认语言、应用/游戏、免费/付费。
3. 填写商店资料：简介、详细介绍、图标、截图、隐私政策。
4. 填写 Data Safety、内容分级、目标受众、广告声明。
5. 上传 `.aab` 到 Internal testing。
6. 测试通过后提交 Production。

## 华为 AppGallery

1. 登录华为开发者联盟并完成实名认证。
2. AppGallery Connect 创建应用。
3. 填写应用名称、分类、介绍、截图、隐私政策链接。
4. 上传签名 APK。
5. 填写隐私声明、权限说明、测试账号和审核备注。
6. 提交审核。

## 小米应用商店

1. 登录小米开放平台并完成开发者认证。
2. 创建应用并填写基础资料。
3. 上传 APK、图标、截图、介绍、隐私政策链接。
4. 补充软著/APP 电子版权、ICP、APP 备案等资质。
5. 填写测试账号和审核说明。
6. 提交审核。

## OPPO 软件商店

1. 登录 OPPO 开放平台并完成认证。
2. 创建移动应用，填写包名和应用资料。
3. 上传 APK、图标、截图、隐私政策、权限说明。
4. 按平台要求补充软著、备案、特殊类目资质。
5. 提交审核。

## vivo 应用商店

1. 登录 vivo 开发者平台并完成认证。
2. 创建应用，填写应用信息和分类。
3. 上传 APK、截图、隐私政策链接、权限用途说明。
4. 填写测试账号和审核备注。
5. 提交审核。

## 应用宝

1. 登录腾讯开放平台/应用宝开发者后台并完成认证。
2. 创建应用，填写包名、名称、分类、介绍。
3. 上传 APK、图标、截图、隐私政策链接。
4. 补充资质、测试账号和审核备注。
5. 提交审核。

## 荣耀应用市场

1. 登录荣耀开发者服务平台：`https://developer.honor.com/home`。
2. 注册/登录荣耀账号并完成开发者实名认证。
3. 创建应用，填写应用名称、包名、分类、简介和详细介绍。
4. 上传 APK、图标、截图、隐私政策链接、账号注销说明和权限用途说明。
5. 按平台要求补充 APP 备案、ICP、软著/电子版权或其他特殊类目资质。
6. 填写测试账号和审核备注后提交审核。

## 暂缓渠道

本轮先放弃 360 手机助手和百度移动应用平台，暂不投入认证和提交流程。

## 三星等后续补充渠道

使用同一资料包复用提交。若审核驳回，优先检查：

- 隐私弹窗与隐私政策内容是否一致。
- 账号注销入口是否可见。
- APP 备案、ICP、软著资料是否缺失。
- 截图是否真实反映 App 功能。
- 包名、签名、版本号是否与上一版一致。
