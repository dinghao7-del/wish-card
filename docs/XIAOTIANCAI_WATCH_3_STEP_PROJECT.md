# 小天才手表客户端三步落地方案

## Step 1：家长审核闭环

目标：孩子从手表端提交后，家长端能看见可信摘要，并完成通过、退回或不通过。

本步完成标准：

- 家长端能识别手表相关任务。
- 待审核详情页展示手表辅助记录。
- 运动估算、照片、地点等证据不夸大、不暴露敏感数据。
- 家长仍是星星发放的最终确认人。

## Step 2：任务创建与手表验证方式

目标：家长创建任务时可以选择是否启用手表验证，以及启用哪种方式。

本步完成标准：

- 任务创建页新增“手表验证方式”。
- 支持不验证、计步、运动时长、动作估算、拍照证明、地点提醒。
- 保存到任务类型或任务扩展描述中。
- 手表预览页能按验证方式展示对应屏幕。

当前实现：

- 创建/编辑目标任务时已出现“手表验证方式”。
- 已支持 6 种选择：不验证、计步、时长、动作、拍照、地点。
- 计步、时长、动作支持目标数值配置。
- 保存时会写入 `watch_*` 任务类型，并在描述里追加可读标记，便于后续迁移到正式字段。
- `/watch-preview` 已加入“创建任务预览”切换器，可直接查看不同验证方式对应的手表端屏幕。

## Step 3：真机 SDK 与发布包

目标：把真机能力接入统一数据结构，并准备小天才发布材料。

本步完成标准：

- 真机计步事件能转成 `WatchActivitySnapshot`。
- 相机/定位/运动传感器按任务场景申请权限。
- 准备审核截图、权限用途说明、隐私说明、兜底流程。
- 完成小天才客户端发布前核对。

当前实现：

- 已新增 `buildWatchNativeBridgePlan(task)`，用于把任务验证方式转成真机 SDK 订阅计划。
- 已新增发布核对清单，区分已准备、待真机、待政策、待人工确认。
- 已生成发布包文档：`docs/XIAOTIANCAI_WATCH_RELEASE_PACKAGE.md`。
